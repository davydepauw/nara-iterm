# Nara

A cool dark color theme for iTerm2, ported from [Nara for VS Code and Cursor](https://github.com/davydepauw/nara-vscode). Pond-stone blue-grey, sea-foam teal, and lantern gold.

## Install

1. In iTerm2, open **Settings → Profiles → Colors → Color Presets… → Import…**
2. Choose `schemes/Nara.itermcolors` or `schemes/Nara High Contrast.itermcolors`.
3. Open **Color Presets…** again and select **Nara** or **Nara High Contrast**.

Double-clicking a `.itermcolors` file imports it the same way. To pick up a newer copy of a preset you already imported, import the file again and reselect it.

## ANSI

Normal colors use the palette above. Bright colors are the same hues, lifted so bold text stays distinct. Black is a darker stone surface. White matches the foreground, and bright white is `#FFFFFF`. Links, underlines, and badges use the teal accent.
